# 01 — Projekt-Modal auf Bild, Beschreibung und Repository-Tabs umstellen

**What to build:** Besucher können jedes Projekt weiterhin über die Kachel öffnen und im Modal zwischen Bild, Beschreibung und externen Repository-Referenzen wechseln.

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [ ] Das Projektmodell unterstützt Bild, Beschreibung und mehrere Repository-Referenzen.
- [ ] Das Modal bietet rechts oben einen Dreifach-Toggle für die verfügbaren Inhalte.
- [ ] Tabs ohne Inhalt werden automatisch ausgeblendet.
- [ ] Repository-Referenzen werden als externe Links dargestellt.
- [ ] PDF-Anzeige und PDF-spezifische Projektlogik sind entfernt.
- [ ] Projektkacheln öffnen weiterhin das Modal.

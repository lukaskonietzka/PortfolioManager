# 04 — Interaktive CV-Timeline

**What to build:** Die CV-Ansicht erhält eine visuelle, interaktive Timeline für ihre sechs Kapitel. Besucher können über nummerierte Punkte zu Kapiteln scrollen und erkennen beim normalen Scrollen automatisch den aktuell sichtbaren Abschnitt.

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [ ] Die sechs CV-Kapitel werden in der festen Reihenfolge als nummerierte Punkte 01–06 dargestellt.
- [ ] Die Timeline steht auf größeren Bildschirmen links neben dem CV-Inhalt und bleibt sticky sichtbar.
- [ ] Ein Klick auf einen Punkt scrollt weich zum zugehörigen Kapitel.
- [ ] Der aktive Punkt wird anhand des sichtbaren Kapitels automatisch aktualisiert.
- [ ] Die Timeline bleibt mit Tastatur und vorhandenen Testwerkzeugen bedienbar.
- [ ] Tests decken Navigation und automatische Aktivierung mindestens auf Komponentenebene ab.

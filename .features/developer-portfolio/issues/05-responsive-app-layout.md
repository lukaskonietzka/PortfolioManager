# 05 — Responsive Layout für die gesamte App

**What to build:** Die komplette Portfolio-App passt sich kleinen und großen Bildschirmbreiten an, ohne horizontales Überlaufen. Die CV-Timeline wird mobil als kompakte horizontale Nummernleiste oberhalb der Inhalte dargestellt.

**Blocked by:** 04 — Interaktive CV-Timeline

**Status:** ready-for-agent

- [ ] Portfolio-Layout und Projektkarten funktionieren auf kleinen Bildschirmbreiten.
- [ ] Header und Navigation bleiben auf kleinen Bildschirmbreiten nutzbar.
- [ ] Das Projekt-Modal passt sich an kleine Bildschirmbreiten an und erzeugt keinen horizontalen Überlauf.
- [ ] Die CV-Inhalte und die Timeline sind mobil lesbar und bedienbar.
- [ ] Die mobile Timeline bleibt anklickbar und zeigt den aktiven Abschnitt korrekt an.
- [ ] Tests oder Build-Validierung bestätigen das responsive Verhalten, soweit es mit der bestehenden Toolchain prüfbar ist.

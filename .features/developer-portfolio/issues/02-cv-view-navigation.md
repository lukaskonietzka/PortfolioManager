# 02 — Lebenslauf-Ansicht mit JSON-Konfiguration und Navigation ergänzen

**What to build:** Besucher können innerhalb der React-App zwischen Portfolio und einer strukturierten Lebenslauf-Ansicht wechseln.

**Blocked by:** 01 — Projekt-Modal auf Bild, Beschreibung und Repository-Tabs umstellen.

**Status:** ready-for-agent

- [ ] Der Header bietet eine Navigation zwischen Portfolio und Lebenslauf.
- [ ] Der Wechsel erfolgt ohne eigene URL und ohne Routing-Abhängigkeit.
- [ ] Lebenslauf-Inhalte werden aus der JSON-Konfiguration geladen.
- [ ] Die Kapitel erscheinen in der Reihenfolge Kurzprofil, Berufserfahrung, Kenntnisse und Technologien, Projekte, Forschung, Ausbildung.
- [ ] Berufserfahrung und Forschung unterstützen die in der Spezifikation festgelegten Felder.
- [ ] Optionale leere CV-Inhalte werden nicht als leere Bereiche dargestellt.
